MintVID 1.0 - third-party licence index
=======================================

MintVID's own source code is MIT-licensed. See LICENSE in the project root.
The mrplay binary also contains or links code from third-party projects with
their own licence terms. Keep the accompanying licence and notice files with
binary distributions, and provide corresponding source where the applicable
licence requires it.

Project / complete source tree:
  https://github.com/boingball/MintVID

For the pinned dependency revisions used by MintVID, clone recursively:
  git clone --recurse-submodules https://github.com/boingball/MintVID.git
